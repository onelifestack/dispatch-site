Support

We are a small team and we read every message.

Write to us

Email hello@onelifestack.com. Say which version you use (Menu in the app, or the changelog) and whether it is the desktop app, the web app or the CLI. Please do not send secrets or whole collections; describe the request instead.

Common questions

Is Dispatch free?

Yes. There are no accounts, ads or paid tiers.

Where is my data stored?

On your device. The desktop app and the web app both keep collections, environments and history in local storage (IndexedDB). With collections as files on desktop, the folder you choose holds them too. We run no server that receives your data.

Does it send anything besides my requests?

No. Dispatch has no analytics, no crash reporting, no update check and no fonts or scripts from other sites. The only network traffic is the requests you send.

What happens to my secrets?

Secret variables, passwords, tokens, keys and Authorization or Cookie headers are encrypted before they are stored, using a key that stays on the device and cannot be exported. A copy of the database moved to another device cannot read them. Exports and backups leave secrets out.

What if I clear my browser data?

The web app keeps its data in that browser, so clearing site data erases it. Use Menu, Export backup now and then. The desktop app is not affected by browser data.

Why does the web app say servers must allow CORS?

A web page can only read responses from servers that permit it. If a server does not, use the desktop app, which has no such rule.

Can it replace my current API client?

It can import Postman collections and environments, Insomnia exports, Bruno folders, OpenAPI files, HAR files and curl commands, so you can try it on your own collections. Check the feature list for what you rely on.

Are the installers signed?

Not yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch. The download page explains how to open them.

Does it sync between devices?

Not now. Export a backup or keep a collection folder in git.

Is there a mobile app?

No. The web app works in a phone browser but is built for a larger screen.

How do I get help or report a problem?

Write to hello@onelifestack.com.
