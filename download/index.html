No install: the web app

The same app runs in your browser and keeps its data in that browser. It can only reach servers that allow it through CORS, and it has no gRPC, mock server or collection folders. See desktop or web.

Command line

The command-line runner runs collections in CI and needs Node.js 20 or newer.

The installers are not signed yet

Windows and macOS will warn you the first time you open Dispatch. That is expected for an app without a paid code-signing certificate, and it does not mean the file is damaged.

Windows

SmartScreen shows “Windows protected your PC”. Choose More info, then Run anyway.

macOS

Gatekeeper says it cannot verify the app. Open the .dmg and drag Dispatch to Applications. Then Control-click the app, choose Open, and confirm. If that option is missing, open System Settings, Privacy & Security and choose Open Anyway next to the message about Dispatch.

Linux

There is no signing warning. Install the .deb with sudo apt install ./file.deb or the .rpm with sudo dnf install ./file.rpm. For an AppImage, make it executable (chmod +x file.AppImage) and run it.

Check the SHA-256 checksum next to each download before you open it. Dispatch does not update itself, so come back here for new versions.
